| 2026-10-07 | 五候选择一 | 候选：A 基坑监测判读预警 / B 基桩低应变曲线判读 / C 公路技术状况评定 / D 竣工档案归档核查 / E 测量控制网平差。**用户选定 C（本题）与 A（兄弟仓库）** |

| 2026-10-07 | 首期只做路面 PCI，桥隧与路基留扩展 | 桥隧各自另有评定标准，全做必然范围失控；且 PCI 数据可由程序合成并标注真值 |
| 2026-10-07 | 弃 B / D / E | B 信号处理风险高；D 业务对象偏城建档案；E 教学级平差脚本众多，**开源空白论据弱** |
| 2026-10-07 | 弃"构件/结构验算类" | 与用户 `steel-design-checker`、`scaffold-formwork-checker`、`structural-strengthening-checker` 的"规范公式验算+文本核查"形态同构 |
| 2026-10-07 | 与造价/招投标产品的边界 | 不做工程量清单与定额计价（属另一条产品线），避免与 `bidding-document-checker` 的合同文书对象邻近 |
| 2026-10-07 | 交付形态 | Windows 免安装 exe（PySide6 + PyInstaller onedir）+ 同一内核 CLI；**不参赛，发 GitHub**；政策文号降级为可信度加分项，核对不过则删锚点 |
| 2026-10-07 | 命名 | 目录 `10-7-road-mqi-checker`，仓库名 `road-mqi-checker`。弃 `pavement-condition-checker`（范围不止路面，MQI 含多分项）、弃 `highway-mqi-assessor`（"assessor"易被读成出决策，违反辅助定位红线）。改名用 `mv`，前后名记入本表 |
