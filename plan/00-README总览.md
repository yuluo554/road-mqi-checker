## 快速开始（当前状态 = M0 骨架）

```bash
py -m venv .venv
.venv\Scripts\activate
python -m pip install -U pip setuptools wheel
python -m pip install -e .[dev]

rmqc selfcheck      # 数据目录 / 规则集 / 系数门 / 台账 schema
rmqc ruleset show   # 15 格系数逐个为 pending（生效 0 → 不出数是设计）
rmqc ledger tables  # SQLite 台账七张表结构
python -m pytest    # 守门测试
```

`import / assess / aggregate / compare / bench / report / gui` 当前返回退出码 3 并指明所属里程碑。

**继续开发**：新对话用 `plan/HANDOFF-M1.md` 续接（M1 数据先行），或直接点名从 M2 起。
