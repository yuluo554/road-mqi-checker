| 2026-10-07 | **M1 拍板：两层判据分界** | 导入层只拒"存不进台账"的行（`R001/R008/R009/R010`）；负值/超范围/单位错/悬空/重叠/闭合差照常入库，由校验层出 finding 并带同一套拒因代码（`CHECK_KIND_TO_REJECT_CODE`）。理由：`ledger.db` 表上刻意不设 CHECK 约束，异常数据被数据库挡掉就断了"导入回执 + 异常召回"这条主证据链 |
| 2026-10-07 | **M1 拍板：台账 schema v2** | `segment` 增可空列 `lane_count` / `segment_width_m` / `panel_count`。理由：几何上界与水泥按板数扣分的分母必须能从台账复算，不能只活在 CSV 里；缺列时校验判"未判定"而不是默认合格 |
| 2026-10-07 | **M1 拍板：白名单按数据类别生效** | `# data_class=SYNTHETIC` 标记的文件强制白名单（真实形态标识符逐行拒入）；用户真实台账用 `--data-class user` 显式声明后不施加；无标记无声明一律拒读，声明与标记冲突也拒。弃"对所有输入施加白名单"（那样 `G25` 都导不进去，工具就废了）；也弃"默认不检查"（红线靠猜就等于没有） |
| 2026-10-07 | **M1 拍板：闭合差不硬判** | 容差格 `tolerance.length_closure` 仍 `pending` ⇒ 校验输出实测差值 + "待核对，未判定"；闭合差为 0 的格子不报（任何非负容差都容得下 0，不需要未核对的容差背书）。有测试同时验证"换成可计算状态后同一判据真的会判"，防止把"未判定"当成没实现 |
| 2026-10-07 | **M2 拍板：评定路径必需系数集合 = 真值支配格** | `pci.engine.surface_table_keys(surface)` 六格（扣分比率、三个分项、合成权重、分级阈值）与 `TRUTH_GOVERNING_KEYS` 的 pci/grade 两列支配格一一对账（有测试）。理由：必需格少于支配格会出现"真值有数、引擎拒算"的假账；多于支配格则相反。弃"引擎自己另列一张必需格表" |
| 2026-10-07 | **M2 拍板：含异常数据出 blocked，不跳过破损行** | 台账里被 M1 判为 `found` 的破损字典/量纲/负值超范围/重复导入对象，评定结果 `blocked` + 数值字段全空。弃"跳过那条破损行算一个数"（那等于把可疑数据当不存在，给出一个看起来正常的分）。悬空/重叠/闭合差/划分变更**不**阻断本段评定（它们坏的是里程账与跨年可比性，不坏"这段扣了多少分"），交由 M4 处理 |
| 2026-10-07 | **M2 拍板：真值取落盘文本 + 复用导入层的行身份** | `_probe_input()` 用即将写入 CSV 的文本值拼评定核输入，并按 `importer.DUPLICATE_KEY_COLUMNS` 的同一身份列去掉文件内重复行（导入层 `R008` 本来就会拒它）。理由：真值必须描述"进了台账的那本账"，否则真值与评定通路的输入不是同一份数据，复算误差这项指标就失去意义 |
| 2026-10-07 | **M2 拍板：贡献合计恒等于满分减 PCI** | 破损扣分与实测指标扣分都按 `分项权重 / 参与权重和` 折算到 PCI 尺度，于是 `Σ 贡献 = 100 − PCI`（未舍入前恒等）。弃"贡献只记分项尺度"（那样用户看到的加总与 PCI 对不上，展开视图就只是装饰） |
| 2026-10-07 | **M2 拍板：缺测分项转 partial，不补 0 也不摊分** | 检测列为 `NULL` 时该分项不参与加权，权重按参与分项归一，整体状态 `partial` 并在 `scope_note` 点名"哪个分项因哪一列缺测被剔除"。弃"缺测当 0 分"（会系统性压低评分）、弃"缺测即整段拒算"（演示数据的水泥路段一律不测车辙，会把全部水泥对象打成 blocked） |
| 2026-10-07 | **M2 拍板：夹具规则集只多两个测试包** | `tests/fixtures/pci-fixture-{asphalt,cement}.json` 承载"已核对形态"的换算通路，数值刻意避开任何真实规范数字。交付面（`data/` + 内置规则集）仍全 `pending`，红线测试继续反向断言 `fixture` 字样不出现在交付面 |

## 快速开始（当前状态 = M2 评定内核）

```bash
py -m venv .venv
.venv\Scripts\activate
python -m pip install -U pip setuptools wheel
python -m pip install -e .[dev]

rmqc selfcheck      # 数据目录 / 规则集 / 系数门 / 台账 schema
rmqc ruleset show   # 15 格系数逐个为 pending（生效 0 → 不出数是设计）
rmqc ledger tables  # SQLite 台账七张表结构（schema v2）
rmqc bench generate # 重生成演示数据：内容一致则逐字节不动
rmqc --db ledger.sqlite import --file data/raw/S99-2022.csv --year 2022  # 入库 + 回执 + 八类校验
rmqc --db ledger.sqlite assess --year 2022   # 逐路段 PCI 评定与扣分展开（系数未核对 → 全部 blocked，退出码 1）
python -m pytest    # 守门测试
```

`aggregate / compare / bench run / report / gui` 当前返回退出码 3 并指明所属里程碑。

**继续开发**：新对话用 `plan/HANDOFF-M3.md` 续接（M3 规则与条款查证），或直接点名从 M4 起。
